# Demo video script (about 2 minutes)

Record at 1440×900 in a clean browser profile with Freighter on **Mainnet**.
Have two wallets ready: *Creator* (no jar yet) and *Fan* (a few XLM).

| Time | Screen | Say |
|---|---|---|
| 0:00 | Landing page, hero | "This is StarJar: tip jars for creators on Stellar, where nobody pays gas." |
| 0:10 | Scroll to the stats | "These numbers come straight from the contract on mainnet." |
| 0:18 | Open your jar → Connect (Creator wallet) | "A creator connects any Stellar wallet…" |
| 0:28 | Fill handle, name, bio → Open jar | "…claims a handle. The wallet shows a fee line, but the creator is not charged it." |
| 0:45 | Dashboard: copy link | "Their jar is a link they can put anywhere." |
| 0:52 | Open the link in a second window, connect Fan wallet | "A fan opens it…" |
| 1:00 | Choose 1 XLM, write a message, Tip | "…picks an amount, adds a message and signs once." |
| 1:12 | Success screen → View on explorer | "Five seconds later it's on chain. Look at the transaction: it's a fee bump. The fee source is the StarJar sponsor, the inner transaction is signed by the fan." |
| 1:30 | Fan wallet balance | "The fan's balance went down by exactly 1 XLM. No fee." |
| 1:38 | Creator dashboard refresh, tip with message | "And the creator has it, with the message." |
| 1:48 | GitHub repo, SECURITY.md | "The contract, the sponsor's policy and its tests, and the security review are all open source." |
| 1:58 | Landing page | "StarJar. Tip any creator, pay zero gas." |
